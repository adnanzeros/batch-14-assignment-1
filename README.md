# Batch 14 Assignment 1

A responsive web design project created as part of the Batch 14 assignment. The project is built with HTML and CSS, with supporting image assets.

## 📌 Project Overview

This project demonstrates a structured webpage built using semantic HTML and custom CSS styling. It focuses on layout, typography, spacing, visual presentation, and responsive-friendly web design.

## ✨ Features

- Responsive webpage layout
- Custom CSS styling
- Structured HTML content
- Image and asset integration
- Clean and organized project structure
- Assignment requirements included in `prompt.md`

## 🛠️ Technologies Used

- HTML5
- CSS3
- Images / static assets

## 📂 Project Structure

```
batch-14-assignment-1/
├── images/
├── style/
├── index.html
└── prompt.md
```

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/adnanzeros/batch-14-assignment-1.git
```

2. Open the project folder:

```bash
cd batch-14-assignment-1
```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for a better development workflow.
