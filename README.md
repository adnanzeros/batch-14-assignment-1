# 🚀 DevConf 2026 — Developer Conference Landing Page

A responsive **developer conference landing page** built with HTML and CSS as part of a Batch 14 frontend assignment.

The project presents a modern DevConf 2026 event website with a hero section, speaker profiles, pricing plans, developer achievements, and footer navigation.

## 🖼️ Preview

![DevConf 2026 Preview](./images/banner.jpg)

## 📌 Project Overview

This project demonstrates how a complete event-focused webpage can be structured and styled using semantic HTML and custom CSS.

The page includes:

- Developer conference hero section
- Speaker showcase
- Conference pricing plans
- Developer achievement section
- Responsive-friendly layout
- Custom images and visual assets
- Structured navigation and footer

## ✨ Main Features

- 🎤 **Speaker Showcase** — Displays conference speakers with their roles and categories.
- 💳 **Pricing Plans** — Standard, Pro, and Team registration plans.
- 🏆 **Developer Achievements** — Frontend, AI, open source, networking, hackathon, and speaker-focused achievement cards.
- 📱 **Responsive Layout** — Designed for different screen sizes.
- 🎨 **Custom UI** — Custom CSS styling, typography, spacing, cards, buttons, and sections.
- 🖼️ **Image Assets** — Uses local speaker, logo, and banner images.
- 🧭 **Navigation** — Includes Speakers, Schedule, Tracks, Venue, and Blog navigation items.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts — Inter
- Static image assets

This is a static HTML/CSS project and does **not** require npm packages or external JavaScript libraries.

```bash

```

